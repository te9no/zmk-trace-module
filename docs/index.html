仮想GPIOマトリクス

Physical Layout

physical layout の `keys` が見つかると、ZMK Studio風の物理配置を表示します。

Input Preview

`zmk,keymap-sensors` と keymap の `sensor-bindings` を読むと、回転イベントをシミュレートできます。

Live Input

KeyboardをONにすると、実キー入力を現在のkeymapから逆引きして仮想GPIO入力にします。PointerをONにすると、この領域上のマウス移動/ホイール/クリックをinput eventとして扱います。
Keyboard OFF Pointer ON
ここをクリックしてから、実キーボードやマウスを操作

Trace Device

ZMK trace moduleがJSON LinesをUSB CDC serialへ出す場合、ここから実機traceを受信できます。localhostまたはHTTPSで開く必要があります。
